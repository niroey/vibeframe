# VibeFrame

> **생각한 화면을, 바로 만들고 바로 실행하세요.**

VibeFrame은 디자인 툴처럼 화면을 직접 만들고, AI에게 말로 수정을 요청하고, 실제 서비스 코드까지 만들어 주는 AI UI 빌더입니다.

---

## 🚀 실행 방법

```bash
git clone <repository-url>
cd VibeFrame
npm install
npm run dev
```

실행 후 터미널에 표시된 주소로 접속하세요.

### MySQL 설정

MySQL은 **선택 사항**입니다.

기본 기능은 MySQL 설정 없이도 실행할 수 있으며, 프로젝트 저장 등 DB가 필요한 기능을 사용할 경우 `.env`에 MySQL 정보를 설정하면 됩니다.

```env
DATABASE_URL=mysql://username:password@localhost:3306/vibeframe
```
