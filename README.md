# VibeFrame

> **생각한 화면을, 바로 만들고 바로 실행하세요.**

VibeFrame은 디자인 툴처럼 화면을 직접 만들고, AI에게 말로 수정을 요청하고, 실제 서비스 코드까지 만들어 주는 AI UI 빌더입니다.

복잡한 툴을 배울 필요도, 처음부터 코드를 작성할 필요도 없습니다.

---

## 만들고 싶은 것을 선택하세요

웹사이트를 만들고 싶나요? 모바일 앱 화면을 만들고 싶나요?

VibeFrame을 열고 사용할 닉네임만 입력하면 바로 시작할 수 있습니다.

```text
닉네임 입력 → 프로젝트 시작 → 화면 만들기
```

비밀번호나 복잡한 가입 절차 없이, 내 작업 공간으로 바로 들어갑니다.

## 눈으로 만들고, 손으로 다듬으세요

왼쪽에서 Text, Button, Image, Input, Card 같은 요소를 골라 캔버스로 끌어다 놓으세요.

- 원하는 위치에 놓기
- 위아래 순서 바꾸기
- 마우스로 크기 조절하기
- 배경·글자·테두리 색 바꾸기
- 둥근 모서리와 여백 조절하기

화면을 보면서 바로 편집하니, 결과를 상상할 필요가 없습니다.

## AI에게 자연스럽게 말하세요

어려운 설정 대신, 평소 말하듯 요청하세요.

```text
버튼을 조금 더 크게 해줘
이 카드 테두리를 부드러운 파란색으로 바꿔줘
로그인 화면을 만들어줘
모바일에서 보기 좋게 정리해줘
```

AI가 현재 화면을 이해하고 필요한 부분을 수정합니다. 마음에 들지 않으면 언제든 Undo로 되돌릴 수 있습니다.

## 한 번 만든 디자인을 계속 쓰세요

자주 쓰는 카드, 헤더, 버튼 묶음은 재사용 컴포넌트로 만들 수 있습니다.

한 번 만든 뒤 필요한 화면마다 추가하고, Variant로 스타일을 나누어 관리하세요. 같은 디자인을 매번 다시 만들 필요가 없습니다.

## 완성된 화면을 실제 코드로

디자인만 남기지 않습니다.

- 웹 프로젝트는 **React 코드**로
- 앱 프로젝트는 **Flutter 코드**로

바로 내보낼 수 있습니다. 만든 화면은 이제 시작점이 아니라, 실제 제품으로 이어지는 결과물입니다.

## 당신의 작업은 계속 이어집니다

사용자별 작업 공간에서 만든 화면과 프로젝트는 저장됩니다. 다음에 다시 들어와도 이어서 만들 수 있습니다.
